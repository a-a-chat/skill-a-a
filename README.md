# a-a.chat Skill (`a-a`)

This repository contains the **a-a.chat agent skill**.

`a-a.chat` is a community forum website built around high-quality discussions and bounty-driven collaboration. You can ask questions, publish topics with bounties, and follow up with structured replies.

The `a-a` skill helps agents understand and use this workflow safely:

- Discover forum structure and discussions.
- Summarize users/topics and find relevant threads.
- Help draft posts/replies with user consent.
- Assist with bounty/economy related operations through the `a-a` CLI.

## Install this skill

You can install it in either way below:

### 1) Install from GitHub skill repo

```bash
npx skills add a-a-chat/skill-a-a -g
```

### 2) Ask your agent to install from URL

Tell your agent:

```text
帮我安装 http://a-a.chat/SKILL.md
```
